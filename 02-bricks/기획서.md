# 레부엘토 벽돌깨기 기획서

## 1. 제작 목표

브라우저에서 자바스크립트로 실행하는 1인용 벽돌깨기 게임을 만든다. 엔진 모양의 바를 좌우로 움직여 공을 튕기고, 배기관 모양의 벽돌을 모두 부수면 승리한다. 니트로를 발동하면 바가 레부엘토로 변신해 배기관을 향해 돌진해 폭발하고 주변 배기관을 부순다.

이 문서의 기본값은 별도 수정 요청이 없으면 제작 기준으로 적용한다. 첨부 사진은 아래 가공 기준에 따라 사용한다. 서킷 배경과 배기음 파일은 제작 전 확인한다.

## 2. 화면과 배치

| 항목 | 제작 기준 |
| --- | --- |
| 화면 | 1024 × 768 모니터에 최적화한다. 브라우저 주소 표시줄 등으로 실제 표시 공간이 작으면 게임 전체를 같은 비율로 줄여 스크롤 없이 표시한다. |
| 벽돌 | 가로 100px, 세로 42px을 기본값으로 사용한다. 첨부 배기관 사진에서 따낸 배기관의 윤곽을 보여 준다. |
| 벽돌 배열 | 가로 9개씩 7층, 총 63개를 화면 위쪽에 가운데 정렬한다. 좌우 간격은 8px, 층 사이 간격은 6px로 한다. |
| 조작 바 | 가로 150px, 세로 36px을 기본값으로 사용한다. 화면 아래쪽에 엔진 모양으로 표시한다. |
| 배경 | 자동차 서킷을 주변 배경으로 쓰고, 배경을 제거한 첨부 레부엘토 이미지를 서킷 위에 합성한다. 공과 배기관이 잘 보이도록 배경 밝기를 낮춘다. |
| 안내 | 시작 방법, 남은 공, 남은 벽돌, 연료통 수집 진행도, 보유 니트로 수, 소리 켜기·끄기를 게임 화면 안에 표시한다. |

픽셀 수치는 게임 내부의 기준 크기다. 화면을 축소할 때 공과 벽돌의 위치와 크기도 함께 줄어든다.

## 3. 게임 규칙과 조작

- 시작 화면에서 스페이스바를 누르면 공이 발사되고 게임이 시작된다. 시작 전에는 공이 바 위에서 대기한다.
- 왼쪽과 오른쪽 방향키로 바를 움직인다. 바는 경기장 밖으로 나가지 않는다.
- 공이 벽이나 바에 닿으면 튕긴다. 벽돌에 닿으면 공이 튕긴다. 공이 움직인 시간이 5초 쌓일 때마다 남은 배기관에 푸른 장갑이 생긴다. 첫 타격에는 장갑이 벗겨지고 두 번째 타격에 배기관이 깨진다. 다음 강화 주기가 먼저 오면 장갑이 다시 생긴다.
- 남은 공은 3개로 시작한다. 엔진 바로 공을 받아내지 못해 공이 화면 아래로 떨어지면 남은 공을 하나 차감하고, 첨부 만화 이미지와 공을 놓쳤다는 문구를 경기장 중앙에 약 1초간 표시한다.
- 공이 남아 있으면 만화 이미지 연출이 끝난 뒤 기존 벽돌 상태를 유지한 채 스페이스바로 다음 공을 발사한다. 마지막 공을 놓쳤을 때도 만화 이미지가 먼저 나온 뒤 패배 화면으로 넘어간다.
- 벽돌을 모두 부수면 승리하고, 공을 모두 잃으면 게임이 끝난다. 결과 화면에서 스페이스바로 새 게임을 시작할 수 있다.

## 4. 니트로 스킬

- 공이 움직이는 동안 N 키 또는 화면의 ‘니트로’ 버튼으로 발동한다. 시작할 때 니트로 1개를 받고 발동할 때마다 1개를 쓴다. 공을 놓쳐도 모아 둔 연료와 니트로는 유지한다.

1. **변신** — 현재 조작 바가 있는 자리에서 엔진 이미지가 첨부 사진 속 레부엘토로 바뀐다.
2. **공간 왜곡과 돌진** — 차량이 배기관을 향해 돌진하는 동안 차량 주변의 서킷 배경이 물결처럼 휘어지고, 차량 뒤로 짧은 잔상이 남는다.
3. **차량 폭발** — 첫 충돌 순간 레부엘토가 불꽃과 연기 속에서 폭발해 사라지고, 충격파가 충돌 지점에서 퍼져 나간다.
4. **배기관 파괴** — 폭발 직후 충격파가 닿는 순서에 맞춰 배기관이 충돌 지점 가까운 곳부터 깨지며 금속 파편이 흩어진다.

- 첫 충돌 지점에서 가까운 순서로 남아 있는 벽돌을 최대 10개 부순다. 벽돌이 10개 미만이면 남은 벽돌을 모두 부순다. 니트로는 장갑도 함께 파괴한다.
- 변신부터 배기관 파괴 연출이 끝날 때까지 공을 잠시 멈춘다. 효과가 끝나면 발동 위치에 엔진 바가 다시 나타나고 공이 다시 움직인다. 니트로로 마지막 벽돌을 부수면 효과가 끝난 뒤 승리 화면을 표시한다.

## 5. 벽돌 폭발 효과

- 공이나 니트로로 배기관이 깨질 때마다 해당 위치에서 밝은 섬광이 한 번 번쩍이고, 불덩이와 버섯구름 모양의 연기가 솟는다. 주변 서킷 화면은 퍼지는 원형 충격파를 따라 잠깐 일그러지며, 금속 파편이 바깥으로 튄다.
- 공으로 깬 벽돌은 즉시 사라지며 공의 움직임은 이어진다. 섬광과 연기는 충돌 지점 위주로 표시해 그 뒤에도 공과 엔진 바의 위치를 볼 수 있게 한다.
- 니트로에서는 레부엘토가 먼저 크게 폭발하고, 충격파를 따라 깨지는 배기관마다 같은 효과를 짧게 연달아 보여 준다. 여러 폭발이 겹치면 불덩이와 연기가 이어져 보이도록 하며, 화면 전체가 반복해서 번쩍이지 않게 한다.

- 배기관 벽돌이 하나 깨질 때 연료통 하나가 나온다. 공이 움직일 때 연료통이 떨어진다. 엔진 바로 연료통 3개를 받을 때마다 니트로 1개를 추가한다.
- 공이나 니트로로 0.5초 안에 벽돌 두 개를 깨면 왼쪽 아래에서 큰 개구리가 통통 튀어나와 흔들리고, 따봉 두 방! 문구와 함께 서서히 사라진다. 벽돌을 두 개씩 묶어 연출한다.

| 스크린샷 2026-11-20 111554.png | 소음기와 연결 파이프 전체의 윤곽을 따서 배기관 벽돌로 쓴다. 파이프 사이의 흰 배경도 제거한다. |
| 스크린샷 2026-11-20 112735.png | 바깥쪽 노란 배경을 제거하고 공을 놓쳤을 때 사용한다. |
| 스크린샷 2026-11-20 112924.png | 흰 배경을 제거하고 따봉 개구리 연출에 사용한다. |

- 제작할 때 각 사진에서 필요한 대상만 따서 투명 PNG로 저장한다. 원본 사진의 배경, 하단 띠, 화면 아이콘 등 주변 요소를 제거하고 가장자리를 다듬는다. 이미지의 가로세로 비율을 유지하며, 서킷에 합성하는 차량은 접지 그림자와 밝기를 맞춘다.
- 배경음은 슈퍼카 배기음을 반복 재생한다. 스페이스바로 게임을 처음 시작할 때 재생하고, 게임 종료 시 멈춘다. 플레이어는 화면에서 소리를 켜고 끌 수 있다.
- 실제 사진과 음원은 출처와 사용 권한을 확인한 파일을 실습 폴더 안에 저장한다. 게임 실행 중에는 인터넷 연결이 필요 없다.

## 9. 완료 기준

- [ ] 브라우저에서 HTML을 열면 CSS와 자바스크립트가 연결되고 게임 화면이 표시된다.
- [ ] 1024 × 768 모니터에서 브라우저 창을 최대화했을 때 게임과 조작 안내가 스크롤 없이 보인다.
- [ ] 배기관 모양의 벽돌이 가로 9개씩 7층으로 표시된다. 게임 기준 크기에서 벽돌 가로는 100px, 바 가로는 150px이다.
- [ ] 서킷 배경에 레부엘토가 자연스럽게 합성되고, 평소 바는 엔진 모양으로 표시된다. 엔진·차량·배기관의 윤곽에 원본 사진의 배경이 남아 있지 않으며, 이미지 비율이 유지된다.
- [ ] 스페이스바로 시작하고 방향키로 바를 움직일 수 있다. 공으로 벽돌이 깨지며, 공을 3개 잃으면 패배한다. 벽돌을 모두 부수면 승리하고 결과 화면에서 다시 시작할 수 있다.
- [ ] 니트로 사용 시 엔진 바가 레부엘토로 변신한다. 돌진 중 배경 왜곡이 보이고, 차량 폭발 직후 배기관이 충돌 지점 가까운 곳부터 깨진다. 연출이 끝나면 엔진 바와 공이 원래 동작으로 돌아온다. 벽돌이 10개 이상일 때는 10개, 10개 미만일 때는 남은 수만큼 사라지며, 니트로가 남아 있으면 다시 발동할 수 있다.
- [ ] 공과 니트로로 배기관을 깨면 각 파괴 지점에서 섬광, 버섯구름 모양 연기, 충격파, 파편이 보인다. 공으로 깼을 때 공과 엔진 바의 위치를 계속 확인할 수 있다.
- [ ] 공을 놓칠 때마다 바깥 노란 배경을 제거한 만화 이미지와 문구가 약 1초 동안 나타난다. 공이 남으면 다음 발사를 기다리고, 마지막 공을 놓치면 만화 이미지 연출 뒤 패배 화면으로 넘어간다.
- [ ] 벽돌 한 개마다 연료통을 하나 떨어뜨리며, 엔진 바로 3개를 받으면 니트로가 1개 충전된다. 놓친 통은 계산하지 않는다.
- [ ] 공이 움직이는 동안 5초마다 장갑이 생긴다. 장갑을 벗기는 타격에는 연료통이 나오지 않으며, 다음 타격에 벽돌이 깨지고 연료통이 나온다.
- [ ] 0.5초 안에 벽돌 두 개를 깨면 큰 개구리가 튀어나와 흔들리고 문구와 함께 서서히 사라진다.
- [ ] 게임을 시작하면 배기음이 재생되고, 화면에서 소리를 끄고 다시 켤 수 있다. 게임이 끝나면 재생이 멈춘다.
