# 기획서: 자기소개 웹페이지

## 누가 쓰나

수업에서 처음 만난 친구들

## 만들 것

가상의 20대 남성 대학생을 소개하는 한 페이지짜리 웹페이지

## 기능

1. 가상 인물의 이름과 한 줄 소개
   - 이름: 이웅서
   - 별명: 없음
   - 한 줄 소개: 안녕하세요! 산책할 때 음악을 듣고 시계 구경을 좋아하는 이웅서예요.
2. 좋아하는 것 4가지
   - 산책하면서 음악 듣기
   - 혼자서 놀기
   - 누군가와 대화하기
   - 시계 구경하기
3. ‘배경색 바꾸기’ 버튼을 누르면 페이지 배경색이 바뀝니다.

4. 움직임 멈추기와 움직임 재생 버튼으로 차량과 빛줄기의 움직임을 제어합니다.

## 배경 디자인

- 람보르기니 홈페이지의 강렬한 분위기를 참고해 화면을 채우는 어두운 배경에 비스듬한 조명과 금빛 포인트를 넣습니다.
- 화면 가장자리에 금괴와 가상 지폐를 겹쳐 배치합니다. HTML 요소에 CSS로 모양과 색을 입혀 표현합니다.
- 이름과 소개 글 뒤에는 어두운 영역을 두고 밝은 글자를 써서 읽기 쉽게 합니다.
- 배경색 바꾸기 버튼을 누르면 검정과 짙은 남색이 번갈아 나타납니다.

- 첨부한 람보르기니 레부엘토의 앞모습과 뒷모습은 각각 차체 외곽선을 따라 잘라 배경을 가립니다. 두 모습이 소개 카드 뒤를 번갈아 가로지르게 하고, 크기 변화와 흐르는 빛줄기로 주행감을 표현합니다.
- 첨부한 손목시계는 외곽선을 따라 체크무늬 배경을 가리고 화면 오른쪽에 비스듬히 배치합니다.

## 조건

- `index.html` 파일 하나에 HTML, CSS, JavaScript를 모두 넣습니다.
- 외부 라이브러리, 서버, 데이터베이스는 사용하지 않습니다.
- 실명, 연락처, 인물 사진은 넣지 않습니다. 첨부한 차량과 시계 이미지는 HTML 안에 넣어 인터넷 연결 없이 표시합니다.

## 완료 기준

- [ ] `01-intro/index.html`을 더블클릭하면 브라우저에서 바로 열리고 이름, 한 줄 소개, 좋아하는 것 4가지가 보입니다.
- [ ] 배경색 바꾸기 버튼을 누르면 검정과 짙은 남색이 번갈아 나타납니다.
- [ ] 배경에 금괴와 가상 지폐가 보이고, 이름과 소개 글을 읽기 쉽습니다.
- [ ] 차량의 앞모습과 뒷모습이 번갈아 지나가고, 사진의 사각 배경과 시계의 체크무늬가 보이지 않습니다.
- [ ] 움직임을 멈췄다가 다시 재생할 수 있고, 기기의 움직임 줄이기 설정이 켜져 있으면 정지 상태로 시작합니다.
